**Was that enough?**  E = enough · M = wanted more · ? = not sure / not asked
**Why left?**  F = had enough (full) · D = didn't like it · L = had to leave · S = shared · ? = don't know

Rules at the counter:

- The diner's requested portion is always served. Seconds are always available.
- Leave a cell blank if you did not measure it. Do not guess.
- Tokens only. No names.

End of service: cooked in total ______ kg · cooked but not served ______ kg · went to: kept / donated / discarded

To enter this sheet later, type it into `data/templates/plates_import_template.csv` and use Setup → Import.
Column values: `satisfaction` = enough, wanted_more, unsure · `leftover_reason` = none, enough_food, dislike, interrupted, shared, unknown.
